# X (Twitter) フォロー中一括取得＆CSV出力ツール（Chrome拡張機能）

APIを使わず、普段ログインしているブラウザ上でX（旧Twitter）のフォロー中一覧ページを自動スクロールし、以下の情報をCSVファイル（Excel対応・UTF-8 BOM付き）で出力するChrome拡張機能です。

## 出力されるCSV項目
1. **表示名**（絵文字も含めてそのまま取得）
2. **ユーザーID**（`@screen_name`）
3. **フォローされているか**（`フォローされている` / `フォローされていない`）

---

## インストール手順（1分で完了）

1. Google Chrome（または Edge / Brave などのChromium系ブラウザ）を開きます。
2. アドレスバーに以下を入力して開きます：
   ```
   chrome://extensions/
   ```
3. 画面右上にある **「デベロッパー モード」** のスイッチを **ON** にします。
4. 左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. このリポジトリのフォルダ（`x-following-exporter`）を選択します。

---

## 使い方

1. ブラウザで [X (x.com)](https://x.com/) にアクセスし、自分のプロフィールから **「フォロー中」**（`https://x.com/あなたのID/following`）を開きます。
   - ※他人のフォロー中一覧ページやフォロワー一覧ページでも使用できます。
   - ※もし画面右下にパネルが出ていない場合は、ブラウザ右上の拡張機能アイコンから「操作パネルを表示 / 開始」をクリックしてください。
2. 画面右下に表示されるパネルの **「▶ 取得開始」** をクリックします。
3. 自動的にスクロールしながらユーザー情報をリアルタイムで収集します（Xはスクロールすると古い要素が画面から消える仮想スクロール仕様ですが、本ツールはメモリ上に順次蓄積するため取りこぼしません）。
4. 最後まで到達すると自動で停止します（途中で「⏸ 一時停止」を押してもOKです）。
5. **「⬇ CSVダウンロード」** を押すと、`following_アカウント名_日時.csv` がダウンロードされます。
   - 「出力対象」プルダウンで **「全員」「フォローされていない人のみ（片思い）」「相互フォローのみ」** を切り替えて出力することも可能です。
